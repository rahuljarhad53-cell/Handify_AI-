# ✍️ Handify AI – Handwriting Assignment Website

## 📌 About the Project
Handify AI is a simple and user-friendly website designed to help users select and preview their assignment files. The project uses HTML, CSS, and JavaScript.

## 🚀 Features
- Simple and attractive user interface
- Upload assignment files (PDF and images)
- Display the selected file name
- Responsive design for mobile and desktop
- Easy-to-use interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📂 Project Structure
```text
Handify-AI/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💻 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. The website will open in your browser.
